- 原有 137 張 Math & Physics Formula Cards 全部檢閱。

- 已有的比例、二次函數等主題補強原卡；新增內容包括數線、整除、根式、因式分解、三角形全等／相似、四邊形、圓與三心、統計、機率及立體幾何。

- 精確單元對照、逐卡檢閱結果與修改前後內容見 `v216-formula-review.json`。

重點校正：平均量與瞬時量的區別；功—動能與淨衝量需計入全部作用；氣體定律使用絕對壓力；根式、比例與指數的定義域；重根與無實根的區分；非等可能事件不能只數結果數；分組平均是估計值；四分位數採用的算法；圓心角對應優弧／劣弧的區別；垂直高、母線、弧長與角位移的區別。

保留 v215 的非公式題庫、雙語顯示修正及所有原公式卡的分類／題目收藏鍵。公式卡恢復「Formula / 公式與應用」標題並隱藏空白的第二答案區。
